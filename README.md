# tf_web

Source for [tfish.net](https://tfish.net): a single `index.html` with an animated fish bowl.

## Project bubbles

Project bubbles rise through the bowl. Click one to pop it and open a panel with the project's title, description and image.

- Fish steer around bubbles. They don't always make it, and a bubble pops if it hits a fish or the top of the glass.
- A popped bubble comes back from the bottom on its next pass.
- Fish near a pop dart away, then drift back to their path.
- Visitors with reduced motion turned on see still bubbles and no fish reactions.

To edit the projects, change the `projects` array at the top of the bubble code in the `<script>` block. Each entry has a `title`, a `description` and an `image`. The placeholder images are generated by `placeholderImage(...)`; replace them with real paths such as `'img/project-one.jpg'`.

Open `index.html` in a browser to preview. There's no build step.
